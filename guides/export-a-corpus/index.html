Export a Corpus

Vichara stores everything in the browser — no server, no cloud. That means nothing persists automatically between sessions. Exporting a corpus as a .vichara file lets you save your work and reload it later without re-importing or re-running the pipeline.

What a .vichara file contains

A .vichara file is a ZIP archive with two components:

EntryContents
corpus.jsonCorpus manifest: name, document list, metadata (title, author, date, language), NER method and timestamp, and optionally pre-computed UMAP positions.
documents/<filename>The original plain-text files for each document (included when available).

When embeddings have been computed, the UMAP positions are embedded in the manifest so that loading the archive in a future session skips the embedding step entirely.

Tip

Export your corpus after running the NLP pipeline so the archive includes pre-computed embeddings. Anyone who loads the archive — including yourself in a future session — will see the 3D Semantic View immediately without waiting for re-embedding.

How to export

  1. Open the Corpus view.
  2. In the right sidebar, hover over the corpus name you want to export.
  3. A Download icon appears at the right of the corpus row. Click it.
  4. The browser downloads a file named <corpus-name>.vichara.

That is the entire workflow — no settings, no format choices.

How to re-import

Drop the .vichara file onto the Corpus view drop zone, or use the standard file picker. Vichara reads the manifest and reconstructs the corpus, including all metadata and (if present) the pre-computed UMAP positions.

Note

If the archive includes pre-computed embeddings, the Semantic 3D View will be available immediately after loading. If not, you will need to re-run the embedding step by clicking Compute embeddings in the Corpus view.

Sharing with collaborators

A .vichara file can be shared like any other file. The recipient drops it into their own Vichara instance. Because everything is self-contained, no internet connection is needed to load the corpus itself (NER and embedding runs still require a connection for the first model download).

Keep in mind:

  • The archive includes the full text of every document. Make sure you have the right to share the underlying works — public domain Gutenberg imports are fine; copyrighted texts may not be.
  • Annotations are stored in the browser session, not in the .vichara file. Use Export Annotations separately to save reading notes.
